# Nine year old security flaw in Linux—discovered
<p style="color:lightblue;font-style:italic;width:100%;border-bottom:1px solid;">Technology</p>

*Security researchers find a high severity Kernel Vulnerability as repository maintainers scramble to patch zero day*

![](https://images.unsplash.com/photo-1624969862644-791f3dc98927)

<p class="dropcap tech">This week a new vulnerability named "Copy Fail" was made public under <code>CVE-2026-31431</code> was discovered by the <b>Xint Code Research Team</b> at bug bounty platform Theori</p>
<p style="font-size:x-large;text-align:center;margin:0;font-family:sanserif;color:lightblue;"><i>"A single 732-byte Python script can edit a setuid binary and obtain root on essentially all Linux distributions shipped since 2017."</i></p>
