# My Homelab

***

*Trust the cloud or your own hardware?*

This section of my notebook will document my journey in building and maintaining a homelab. A homelab is a personal server environment that allows me to experiment with various technologies, run services, and learn more about networking, virtualization, and system administration; without the cost of customers or expensive cloud services.

![[rack.png]]

My server is called Z-System. *Yeah, I know sounds like the IBM-Z mainframe; but it sounds cool though!*.

It's got various nodes ranging from multiple different performance classes and architecture, all running [[Proxmox]]. Z-System is designed to be self-contained using its own router system and internal network. 

![[Z-System-network-top.png]]

## So why even spend all the money and time to make a homelab?

One primary reason is **privacy** — you know what's on your server and nobody else does.
